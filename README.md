# RAFF Construcciones

**RAFF Construcciones** es un proyecto de desarrollo web creado para una empresa del sector de la construcción. El objetivo es desarrollar una presencia digital profesional que permita mostrar los servicios de la empresa, sus trabajos realizados y facilitar el contacto con potenciales clientes.

El proyecto combina **diseño web, desarrollo frontend y experiencia de usuario**, buscando una estética moderna, profesional y confiable, adaptada a la identidad de la empresa.

La página está pensada para presentar de forma clara los diferentes servicios de construcción, destacar proyectos realizados y ofrecer una navegación sencilla tanto desde computadoras como desde dispositivos móviles.

**Tecnologías y áreas:** HTML, CSS, JavaScript, diseño web responsive, UI/UX y optimización de la experiencia de usuario.
